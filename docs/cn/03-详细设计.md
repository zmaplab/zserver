## 一、ZMap 核心引擎

### 1.1 Map 类

**文件**：`src/ZMap/Map.cs`

Map 是渲染的入口类，采用 Builder 模式链式设置属性。每个 Map 实例代表一次地图渲染请求。

**核心属性**：
- `_layers`：`List<Layer>`，存储所有参与渲染的图层
- `_graphicsServiceProvider`：`IGraphicsServiceProvider`，图形上下文工厂
- `_zoom`：`Zoom`，当前缩放级别/比例尺
- `_srid`：`int`，视窗坐标系（如 4326、3857）
- `Id`：Trace Identifier，用于日志追踪

**核心方法**：

| 方法 | 说明 | 算法要点 |
|------|------|----------|
| `SetZoom(Zoom)` | 设置缩放级别 | 链式调用，返回自身 |
| `SetSrid(int)` | 设置坐标系 | 将 SRID 存储到 `_srid` |
| `SetId(string)` | 设置追踪 ID | 用于关联日志中的请求 |
| `AddLayers(IEnumerable<Layer>)` | 添加图层集合 | 遍历调用 `layer.LoadAsync()` 后加入列表 |
| `GetImageAsync(Viewport, string)` | **核心渲染方法** | 见下方详细说明 |

**`GetImageAsync` 算法流程**：

```
1. 验证 Viewport.Extent 不为空且有效
2. 通过 IGraphicsServiceProvider 创建 SkiaSharp 图形上下文
3. 设置 TraceIdentifier 到图形上下文
4. 倒序遍历 _layers（for i = _layers.Count-1; i >= 0; i--）
   ├── 调用 layer.RenderAsync(graphicsService, viewport, _srid, _zoom)
   └── 倒序保证上层图层不被下层覆盖
5. 调用 graphicsService.GetImage(imageFormat, bordered)
   └── 从 SkiaSharp 画布导出为指定格式的 Stream
6. 返回 Stream
```

**图层倒序渲染（关键设计）**：
- WMS 标准规定 layers 参数最左边的图层在最底层，最右边的在最上层
- 添加图层时按顺序从前到后加入 `_layers` 列表
- 渲染时从列表末尾向前遍历，确保后面的图层绘制在前面图层的上方

### 1.2 Layer 类

**文件**：`src/ZMap/Layer.cs`

Layer 是图层的基类，定义了图层的核心属性和渲染接口。实际渲染时根据 Source 类型分发到不同的渲染分支。

**核心属性**：

| 属性 | 类型 | 说明 |
|------|------|------|
| Name | string | 图层名称 |
| ResourceId | string | 资源组标识 |
| ResourceGroup | ResourceGroup | 资源组 |
| MinZoom / MaxZoom | double | 可见缩放范围 |
| ZoomUnit | ZoomUnits | 缩放单位（Scale/Zoom） |
| StyleGroups | List\<StyleGroup\> | 样式组列表 |
| Enabled | bool | 是否启用 |
| Envelope | Envelope | 显示范围（地理范围） |
| Buffers | List\<GridBuffer\> | 栅格缓冲配置 |
| Source | ISource | 数据源 |
| Services | HashSet\<ServiceType\> | 支持的服务类型（WMS/WMTS） |
| Filter | string | CQL 过滤条件 |

**Layer 类型层次**：
```
Layer（基类）
  ├── VectorLayer（矢量图层，未单独文件，运行时通过 Source 类型判断）
  ├── RasterLayer（栅格图层，同上）
  └── TiledLayer（瓦片图层，同上）
```

**`RenderAsync` 方法算法流程**：

```
RenderAsync(graphicsService, viewport, viewportSrid, zoom)
│
├── [1] 可见性判断
│   ├── 图层未启用 (!Enabled) → return
│   └── 缩放级别不在可见范围 (!this.IsVisible(zoom)) → return
│
├── [2] 样式可见性判断
│   └── 所有 StyleGroup 都不可见 → return（提前退出，避免查询数据）
│
├── [3] 坐标系转换
│   ├── 获取视窗坐标系 (CoordinateReferenceSystem.Get(viewportSrid))
│   ├── 获取数据源坐标系 (Source.CoordinateSystem)
│   └── 将视窗范围转换为数据源范围 (viewportExtent.Transform)
│       └── 使用 ProjNET 的 CoordinateTransformation
│
├── [4] 范围相交判断
│   └── Envelope != null && !Envelope.Intersects(dataSourceExtent) → return
│
├── [5] 数据源类型分支（Switch Source）
│   ├── IVectorSource（矢量）→ RenderAsync 矢量分支
│   │   ├── 获取视窗放大范围（含 buffer）
│   │   ├── 调用 source.GetFeaturesAsync(extent) 获取要素
│   │   ├── 对每个 Feature：坐标系转换 → 简化 → 样式渲染
│   │   └── 样式渲染：遍历 StyleGroups → 遍历 Styles → StyleVisitor.Accept
│   │
│   ├── ITiledSource（瓦片）→ RenderAsync 瓦片分支
│   │   ├── 计算瓦片范围与视窗的交集
│   │   ├── 获取交集内的瓦片列表
│   │   └── 对每个瓦片：获取瓦片图像 → 绘制到画布
│   │
│   └── IRasterSource（栅格）→ RenderAsync 栅格分支
│       └── 调用 source.GetImageAsync(extent) → 绘制到画布
```

### 1.3 Feature 类

**文件**：`src/ZMap/Feature.cs`

Feature 是 GeoJSON 要素的包装类，提供几何对象和属性的封装。

**核心属性与方法**：

| 成员 | 说明 |
|------|------|
| Geometry | NetTopologySuite Geometry 对象 |
| IsEmpty | 判断几何是否为空 |
| `this[string]` | 索引器，通过属性名获取属性值 |
| `GetAttributes()` | 获取所有属性 |
| `Transform(ICoordinateTransformation)` | 坐标系转换（使用 ProjNET） |
| `Simplify()` | VW 简化算法简化几何（避免渲染异常点） |

**Simplify 算法细节**：
- 点类型不简化（跳过）
- 地理坐标系（GeographicCoordinateSystem）：容差 0.00001 度
- 投影坐标系：容差 0.0001 米
- 使用 NetTopologySuite 的 VWSimplifier

#### 2.1.1 GetMapAsync

**算法流程**：

```
GetMapAsync(layers, styles, srs, bbox, width, height, format, transparent, bgColor, time, formatOptions, zFilter, arguments)
│
├── [1] 参数验证
│   └── ParameterValidator.VerifyAndBuildWmsGetMapArguments()
│       ├── layers 非空检查
│       ├── srs 格式检查（必须是 EPSG:N 格式）
│       ├── bbox 解析（4个 double 值）
│       ├── width/height 范围检查
│       ├── 添加默认样式（若未指定）
│       └── 返回验证结果 + 解析后的参数
│
├── [2] 图层查询
│   ├── 构建 LayerQuery 列表（resourceGroup:layer 解析）
│   └── layerQueryService.GetLayersAsync() → 获取 Layer 对象列表
│
├── [3] 权限校验
│   └── 对每个 Layer 调用 permissionService.EnforceAsync("read", layer.ResourceId)
│       └── 权限不足 → 返回 403
│
├── [4] 创建渲染上下文
│   ├── 创建 Viewport（Extent, Width, Height, Transparent, BgColor, Bordered）
│   ├── 计算 OGC Scale（GeographicUtility.CalculateOGCScale）
│   └── 创建 Map 并设置 Srid、Zoom、GraphicsContext
│
├── [5] 渲染
│   └── map.GetImageAsync(viewport, format) → 返回 Stream
│
└── [6] 返回 MapResult
    ├── 成功：MapResult(imageStream, null, null)
    └── 失败：MapResult(Stream.Null, errorCode, errorMessage)
```

#### 2.1.2 GetFeatureInfoAsync

**算法流程**：

```
GetFeatureInfoAsync(layers, srs, bbox, width, height, infoFormat, featureCount, x, y, arguments)
│
├── [1] 参数验证
│   └── ParameterValidator.VerifyAndBuildWmsGetFeatureInfoArguments()
│
├── [2] 图层查询
│   └── 同 GetMap 的图层查询逻辑
│
├── [3] 像素坐标转地理坐标
│   ├── pixelWidth = (bbox.MaxX - bbox.MinX) / width
│   ├── pixelHeight = (bbox.MaxY - bbox.MinY) / height
│   ├── y = height - y （OGC 标准：左上角为原点）
│   └── latLon = GeographicUtility.CalculateLatLongFromGrid()
│
├── [4] 构建查询范围（pixel sensitivity = 10）
│   ├── minX = lon - 10 * pixelWidth
│   ├── maxX = lon + 10 * pixelWidth
│   ├── minY = lat - 10 * pixelHeight
│   └── maxY = lat + 10 * pixelHeight
│
├── [5] 遍历图层执行空间查询
│   ├── 仅处理 SpatialDatabaseSource 类型的数据源
│   ├── 将查询范围转换为数据源坐标系
│   ├── 调用 source.GetFeaturesAsync(targetEnvelope) → 获取要素
│   ├── 限制返回数量（featureCount）
│   └── 收集要素到 FeatureCollection（添加 ___layer 属性标识来源图层）
│
└── [6] 返回 GetFeatureInfoResult
    └── FeatureCollection（GeoJSON）
```

### 2.2 参数验证器

**文件**：`src/ZMap/Ogc/Wms/ParameterValidator.cs`

| 验证项 | 规则 |

## 三、WMTS 实现细节

### 3.1 WmtsService 类

**文件**：`src/ZMap/Ogc/Wmts/WmtsService.cs`

#### 3.1.1 GetTileAsync

**算法流程**：

```
GetTileAsync(layers, styles, format, tileMatrixSet, tileMatrix, tileRow, tileCol, zFilter, arguments)
│
├── [1] 参数预检
│   ├── layers 非空检查
│   ├── tileMatrixSet 非空检查
│   └── GridSetStore.FindAsync(tileMatrixSet) → 查找瓦片矩阵集
│       └── 未找到 → 返回 TileMatrixSetNotDefined
│
├── [2] 缓存检查
│   ├── Utility.GetWmtsPath() 生成缓存文件路径
│   └── File.Exists(fullPath) → 命中则直接返回缓存文件
│
├── [3] 图层名解析
│   ├── 逗号分隔多个图层
│   ├── 冒号分隔 resourceGroup:layer
│   └── 构建 LayerQuery 列表
│
├── [4] 过滤器检查
│   ├── 分号分隔多图层过滤器（与图层一一对应）
│   └── 过滤器数量必须等于图层数量
│
├── [5] 图层查询与权限校验
│   └── 逻辑同 WMS GetMap
│
├── [6] 计算瓦片范围
│   ├── gridSet.GetEnvelope(tileMatrix, tileCol, tileRow)
│   └── 返回瓦片的地理范围 + 比例尺分母
│
├── [7] 创建渲染上下文
│   ├── Viewport（Tile, Extent, TileWidth, TileHeight, Transparent=true）
│   └── Map 设置
│
├── [8] 渲染
│   └── map.GetImageAsync(viewport, format) → 渲染流
│
├── [9] 写入缓存
│   ├── 创建目录（如不存在）
│   ├── 将渲染结果写入缓存文件 (FileStream)
│   └── 文件流 Seek 到起始位置
│
└── [10] 返回 MapResult
```

### 3.2 WMTSController 缓存路径

**文件**：`src/ZMap/Infrastructure/Utility.cs`

```csharp
public static PathInfo GetWmtsPath(string layers, string filter, string format,
    string tileMatrixSet, string tileMatrix, int tileRow, int tileCol, bool bordered)
```

**缓存键算法**：
```
1. layerKey = layers.Replace(',', '.')  // "layer1:ws1,layer2:ws2" → "layer1_ws1.layer2_ws2"
                                            // 冒号变下划线，逗号变点号
2. group = Hash(filter + "_" + bordered)

3. tileMatrixSetPath = tileMatrixSet.Replace(":", "").Replace("/", "_")
   // "EPSG:4326" → "EPSG4326"

4. intervalPath = "wmts/{layerKey}/{tileMatrixSetPath}/{tileMatrix}/{tileRow}/{tileCol}{ext}"
   // 有过滤器时追加 _{group}

5. fullPath = Path.Combine(BaseDir, "cache", intervalPath)
   // 如: /app/cache/wmts/polygon/EPSG4326/5/10/20.png
```

### 3.3 WMTS Actor 键设计

- **Key**：`tuple.IntervalPath`（即 `wmts/{layerKey}/{tileMatrixSetPath}/{tileMatrix}/{tileRow}/{tileCol}_{group}{ext}`）
- **StringKey 路由**：同一 Grid（相同 layerKey + tileMatrixSet）的瓦片通过 Orleans 一致性哈希路由到同一 Silo
- **效果**：同一 Grid 区间的所有瓦片在同一 Silo 上渲染，共享 Silo 级别缓存

## 六、渲染管线

### 6.1 渲染管线架构

```
Style（样式）→ IStyleVisitor（访问者）→ IRenderer（渲染器）→ SkiaSharp 画布
```

### 6.2 样式类型

| 样式类 | 渲染器 | 说明 |
|--------|--------|------|
| FillStyle | FillRenderer | 多边形填充（颜色、透明度） |
| LineStyle | LineRenderer | 线条绘制（颜色、宽度、虚线模式） |
| SymbolStyle | SymbolRenderer | 符号/图标渲染 |
| TextStyle | TextRenderer | 文字标签（字体、大小、颜色、锚点） |
| RasterStyle | RasterRender | 栅格图像渲染 |
| ResourceFillStyle | ResourceFillRenderer | 资源填充 |
| SpriteFillStyle / SpriteLineStyle | 相关渲染器 | 精灵图填充/描边 |

### 6.3 访问者模式

```
IZMapStyleVisitor（接口）
  ├── Visit(FillStyle) → 调用对应渲染器
  ├── Visit(LineStyle) → 调用对应渲染器
  ├── Visit(TextStyle) → 调用对应渲染器
  ├── Visit(SymbolStyle) → 调用对应渲染器
  └── Visit(RasterStyle) → 调用对应渲染器

ZMapStyleVisitor（实现）：将每个 Style 分派到 SkiaSharp 渲染器
SldStyleVisitor（实现）：将 SLD Style 转换为内部 Style 后分派
```

### 6.4 SkiaSharp 渲染流程

```
1. Create SkiaSharp Surface（位图）
2. Clear（背景色/透明）
3. 处理每个 Layer
   ├── 获取 Features / Tile Images
   ├── 遍历 StyleGroups → 遍历 Styles
   │   └── StyleVisitor.Accept(style, feature, graphicsService)
   │       └── Renderer.Render(feature, graphicsService)
   │           ├── SKPaint 创建（颜色、透明度、字体等设置）
   │           ├── SKCanvas 绘制（DrawPath, DrawText, DrawImage 等）
   │           └── SKPaint 回收（缓存）
   └── ...
4. Flush 到 Stream（PNG/JPEG 编码）
```

## 八、动态编译

### 8.1 Natasha 动态编译

**文件**：`src/ZMap.DynamicCompiler/`

- 使用 `Natasha` 库在运行时将 C# 表达式字符串编译为可执行代码
- 用于 CQL 过滤器表达式的运行时求值
- 支持在样式标签中使用模板表达式（如 `{{ feature['name'] }}`）

### 8.2 C# 表达式示例

```csharp
// 样式中的动态表达式
{ "label": "{{ feature['name'] }}" }

// 编译为运行时 LINQ Expression
// Natasha 在运行时解析 {{ }} 模板，编译为可执行的 Func<Feature, string>
```
