## 五、测试执行

### 5.1 运行所有测试

```bash
dotnet test src/ZServer.Tests/ZServer.Tests.csproj
```

### 5.2 运行指定测试

```bash
dotnet test src/ZServer.Tests/ZServer.Tests.csproj --filter "FullyQualifiedName~TransformTests"
```

### 5.3 测试环境要求

| 环境 | 要求 |
|------|------|
| SDK | .NET 10.0 SDK |
| PostgreSQL | 部分测试需要 PostGIS 数据库 |
| GDAL | GDAL 数据源测试需要 |
| 字体 | 中文字体（如 SimSun） |

### 5.4 测试配置

测试配置通过 `appsettings.json` 或环境变量提供：
- `PostgreConnectionString`：PostGIS 连接字符串
- `EnableSensitiveDataLogging`：是否输出敏感数据日志

## 六、测试策略

| 层次 | 策略 | 覆盖率目标 |
|------|------|-----------|
| 单元测试 | 验证单个类/方法的正确性 | 核心逻辑 ≥ 90% |
| 集成测试 | 验证 API → Grain → Service 完整链路 | 关键流程 100% |
| 数据源测试 | 验证各数据源实现 | 每种数据源 ≥ 1 个测试文件 |
| 渲染测试 | 验证渲染输出正确性 | 每种样式类型 ≥ 1 个测试文件 |
| 基准测试 | 衡量渲染性能 | 渲染器 ≥ 3 个基准方法 |
